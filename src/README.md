# 源码归档
问答助手原型归档.zip保存examples内CLI问答原型；MVP源码归档.zip保存本轮可运行工程、Agent、知识库种子、前后端和测试快照。主维护代码仍在根目录app/static/templates，不重复开发两套src实现。
源码归档不包含.env、密钥、运行数据库、索引或用户修改的知识库。原始种子来自本地Git跟踪基线，与生产制度无关，启动前应人工核实。
三人工点：H1员工报销草稿确认；H2后台预约分诊审核及拒绝释放名额；H3管理员提示词版本发布。H2仅演示管理员授权，非真实临床资质认证。详细设计和运行手册见docs/提交补充，量化证据见Test。
归档时间为本轮资料构建时点，不包含后续生成的文档或未来提交；以zip中的源码实际内容为准。
