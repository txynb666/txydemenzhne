- 原始案例机构、角色及指标均为平台合成；不是医院真实经营数据。
- 当前MVP具备制度问答、演示预约、报销草稿与后台功能；未接真实医院、SSO或OA，未实现现场加号和迟到队列调度。
- 原目录中的“需求清单.md”等文件包含远期规划，本次课程材料以本目录的实现范围说明为准。
- 22项Python及6项聊天流前端测试为已有验证记录，不等于模型准确率、生产压力或医疗安全认证。
- DOCX已进行浏览器兼容渲染逐页检查；本机缺少LibreOffice且Office自动化权限受限，尚未完成Word或LibreOffice原生渲染复核。提交前建议用Word或WPS确认分页。
- 未包含真实API密钥、.env、数据库、个人健康记录或实验室登录Cookie。
