# 典型事件采访整理
## 来源与记录范围
来源为2026年11月5日实验室独立训练的导诊护士林亦舟原有4轮问答，原文已导出为典型事件采访记录.txt。不是本轮新采访，不是实际患者记录。最新11月6日JSON属于另一轮访谈，不将两轮拼成同一次采访。
## 事件经过与痛点
受访者描述一类典型异常：医生临时处理急诊，系统排班未同步，患者仍收到准点到诊通知。患者到导诊台后，系统与现场说法不一致。护士先安抚患者，再找排班管理员核对，不自行改顺序。护士同时需处理迟到和加号混排、反复解释与便签交接问题。
## 已有量化依据
原记录引用f12：每日约180次排队咨询。案例其他资料引用每日1600就诊人次。两者是教学场景规模，不是本事件的参与人数或耗时。每轮提问及回答保留原文，不补造具体解释分钟数、投诉量或等待时长。
## 信息缺口
个案发生日期、业务编号、预约与实际到诊时间、通知版本、接手人确认时间、单次解释耗时及最终接诊结果未提供。因此已完成TXT及DOCX整理和至少3轮原对话归档，但“单笔典型事件可复核且量化”的验收仍为PARTIAL，需补原记录。
## AI改造与人工责任
显示来源版本与最后同步时间；冲突时停止确定性承诺并创建人工待办；AI仅整理原记录及解释草稿，排班管理员核对，护士确认后使用。专业分诊和急症处置由医护按院方流程决定。
## 建议补访
围绕同一业务编号逐步询问：发生何时、每个角色何时接到信息；用系统原记录验证预约、签到、通知、解释、接手和接诊时间；把护士初述与排班及工程记录交叉核对。未取得的数据继续标未知，不能用本方案的建议值代替原话。
